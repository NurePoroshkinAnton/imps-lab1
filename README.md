# ЛР1 · Self-healing стенд

Тестові сторінки для лабораторної роботи «Self-healing тести» (Testim).

## Розгортання на GitHub Pages

1. Створіть новий публічний репозиторій на GitHub (наприклад, `testim-lab1`).
2. Завантажте **вміст** цієї папки в корінь репозиторію (Add file → Upload files).
3. Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 хвилини сайт буде доступний за адресою `https://<ваш-логін>.github.io/testim-lab1/`.

## Деталі змін між версіями

**Завдання 2 (кнопка входу).** Поля вводу і блок результату (`#username`, `#password`, `#result`) однакові в усіх версіях, змінюється лише кнопка.

| Версія | id | class | контейнер | текст |
|---|---|---|---|---|
| v1 | `login-btn` | `btn-primary` | `div.form-wrapper` | Увійти |
| v2 | `sign-in-action` | `button-main` | `section.auth-panel > div.actions` (+ посилання поруч) | Увійти |
| v3 | `sign-in-action` | `button-main` | як у v2 | Вхід |

**Завдання 3 (кнопка кошика).** Лічильники `#cart-count` і `#fav-count` стабільні, тож на них зручно робити перевірки.

| Версія | 1-ша кнопка | 2-га кнопка |
|---|---|---|
| v1 | **Кошик**: «Купити», `.action-buy` (помаранчева) | Обране: «В обране», `.action-fav` |
| v2 | Обране: «В обране», `.action-buy` (помаранчева) | **Кошик**: «Додати до кошика», `.cta-cart` |
| v3 | Обране: «Купити пізніше», `.action-buy` (помаранчева) | **Кошик**: «Додати до кошика», `.cta-cart` |

У v2 і v3 кнопка обраного успадковує клас, стиль і позицію старої кнопки кошика. Це провокує хибне відновлення.

**Завдання 4 (каталог).** Тестовий сценарій: додати «Механічна клавіатура» в кошик і перевірити, що «У кошику: 1» і «Товари: Механічна клавіатура».

| Ітерація | Розкладка | Порядок товарів | Кнопка |
|---|---|---|---|
| it0 | сітка 3 колонки | миша, клавіатура, монітор | «Додати в кошик», внизу |
| it1 | список | миша, клавіатура, монітор | «Додати в кошик», праворуч |
| it2 | сітка 2 колонки, вкладені обгортки | монітор, миша, клавіатура | «Додати в кошик», внизу |
| it3 | сітка 3 колонки, вкладені обгортки | клавіатура, монітор, миша | «У кошик», вгорі |

Хеш-класи (наприклад, `_1k9yh6`) змінюються з кожною ітерацією. Варіант A відрізняється від B **лише** атрибутами `data-testid` (`add-to-cart-keyboard`, `cart-count`, `cart-items` тощо), які між ітераціями не змінюються.
